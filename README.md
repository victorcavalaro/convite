# Convite de formatura — Julia Ribeiro

Abra config.js e preencha os valores entre aspas:
- endereco: endereço completo, cidade e estado.
- googleMapsApiKey: chave com Maps Embed API habilitada. Configure a restrição de sites no Google Cloud para o domínio de publicação.
- telefoneWhatsApp: código do país, DDD e número, apenas dígitos.
- mensagemWhatsApp: texto já preenchido; altere se desejar.

O mapa só carrega com endereço e chave preenchidos. Sem telefone, o selo avisa que a confirmação estará disponível em breve. O WhatsApp abre a mensagem pronta; o convidado precisa enviá-la.
Documentação: https://developers.google.com/maps/documentation/embed/embedding-map

As configurações são editadas no arquivo, não pelos convidados. Reenvie config.js à hospedagem depois de editar.

Imagens em telas horizontais / verticais, conforme a correspondência solicitada:

2. 2.jpg / 2p.jpg

O site contém somente estas quatro páginas. A capa preserva a proporção e preenche a tela, recortando apenas as bordas quando necessário. As demais imagens se ajustam à largura e à altura sem corte, podendo mudar de proporção. Abertura da carta da página 1 à 2; rolagem nas demais. A preferência de movimento reduzido é respeitada.
O mapa e o botão são sobrepostos às áreas correspondentes das artes. Os endereços e datas desenhados nas imagens não mudam ao editar config.js: substitua as artes se necessário.
